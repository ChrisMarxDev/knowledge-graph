# kw project purpose and dogfooding

## Purpose
The primary job is supplying useful understanding to agents while making project knowledge glanceable and traversable for humans. Knowledge should remain local and file based. Required reading should grow with the relevant task, not proportionally with accumulated history.

Success first means a felt improvement over managing ordinary Markdown skills in actual work; formal measurement follows useful experience. This repository is now a dogfooding corpus.

## Collection scope
knowledge/nodes contains a curated map of README.md, AGENTS.md, agent-wiki-discussion.md, and repository skills and their references. Original documents remain intact and are cited. Examples, template fixtures, dependencies, build output, personal skills, and external repositories are excluded. This is a curated feature map, not an exhaustive transcript or automatic synchronization. A 2026-10-12 retrospective reconciled the current CLI/UI with focused records for implemented features and corrected outdated layout and installation notes.
